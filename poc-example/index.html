🔐 NL Wallet PoC

Dit is een voorbeeld implementatie van de NL Wallet Web library. Klik op de knop hieronder om een sessie te starten met NL Wallet.

Let op: Voor een werkende PoC heb je nodig:
  • Een draaiende Verification Server (bijv. via scripts/start-devenv.sh)
  • Een backend endpoint op http://localhost:3000/api/sessions/start
  • De NL Wallet app geïnstalleerd (of simulator)
